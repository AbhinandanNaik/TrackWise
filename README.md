# 🚀 TrackWise – Enterprise Asset Tracking System

TrackWise is a enterprise asset tracking and lifecycle management system designed to streamline asset monitoring, risk alerting, and maintenance planning. It integrates modern APIs and intelligent features to enhance operational efficiency.

---

## 📦 Features

- **Product Lifecycle Overview**  
  Visualize and manage the complete lifecycle of enterprise assets.

- **Smart Maintenance Suggestions**  
  Powered by GeminiAI, get predictive maintenance recommendations based on asset usage and risk factors.

- **Asset Risk Alerts**  
  Integrated with NewsAPI to provide real-time alerts on external risks affecting assets.

- **User Signup System**  
  - Normal users can register freely.  
  - Admin registration requires approval from an existing admin.  
  - Signup is linked to the Employee entity.

- **Employee Entity Integration**  
  Includes fields like:
  - First Name
  - Last Name
  - Email
  - Phone
  - Department

---

## 🛠️ Tech Stack

- **Backend**: Spring Boot  
- **APIs**: NewsAPI, GeminiAI
- **Authentication**: Role-based with admin approval  
- **Database**: PostgreSQL
- **Documentation**: Confluence integration for live updates
